# Computer Vision (Semester 7)

This repository contains laboratory tasks and assignments for the Computer Vision course (Semester 7).

## 📁 Repository Structure

### [Lab 01: Deep Features and Classification](./lab01/)
* **`deep_features_and_classification_final.ipynb`**: Jupyter notebook demonstrating feature extraction and classification using pretrained deep learning models.
* **`results.md`**: Report detailing the experimental results, model performances, and analysis for Lab 1.

### [Lab 02: Effect of Image Filtering on Skin-Lesion Classification](./lab02/)
* **`filters-on-ham10000.ipynb`**: Jupyter notebook analyzing the effect of various spatial-domain image filters (Average, Gaussian, Median, Sharpening, Sobel) on the HAM10000 skin-lesion dataset using pretrained models (ResNet101, DenseNet121, XGBoost).
* **`Lab02_Report.md`**: Detailed lab report containing the comparison metrics (Accuracy, Precision, Recall, F1-score, Macro-F1, AUC) and answers to the analytical questions regarding the impact of filtering on deep learning feature extraction.
